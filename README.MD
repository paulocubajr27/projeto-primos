Este projeto foi desenolvido em Python para trabalhar didaticamente com o conceito de números primos.

Arquivos:
* primos.py - Programa principal em Python
* arquivo.txt - arquivo utilizado pelo programa para armazenar dados. 

O objetivo deste projeto é praticar programação em Python com alunos, manipulação de arquivos e comandos no terminal do Linux. 

Como Exectar:
* Para executar digite python3 primos.py

Tecnologias Utilizadas:
* Python 3
* Linux
